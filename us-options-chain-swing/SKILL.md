# us-options-chain-swing

## 用途
读美股个股期权链，找 1–10 天短线方向信号。默认只出价格尺，不写长报告。

## 触发
期权链、异常活动、Vol/OI、Call/Put 墙、IV rank、skew、expected move、近月开仓、读链、个股 ticker。

## 默认输出（v1.4，唯一默认格式）
用户只发 ticker，或说「读链 / 期权链 / 分析」，**只输出下面这种表**。不要大白话、不要表格、不要策略、不要 JSON。

```
TICKER  YYYY-MM-DD  现价 $XXX  数据截止 收盘/盘前

350  9/21 少量 Call（还要涨 · +X%）
345  9/18 Call 偏卖
340  Call墙 / 上方阻力
337.5  9/16 Call 放量（噪声）
335  ★ 主战场（9/18 Call 开仓区）
333  现价
332.5  9/16 涨跌都活跃（到期噪声）
330  Put墙 / 保护
325  Max Pain
320  9/21 Put 放量（偏保护）
```

硬规则：
- 一行一个真实行权价，禁止编造档位。
- 从高到低排。
- 现价那一行只写「现价」，可以不带★。
- 主战场那一行加 ★。
- 注释只用这几种：Call墙 / 上方阻力、主战场（到期+Call/Put+开仓/偏卖）、现价、Put墙 / 保护、Max Pain、噪声、偏保护、偏卖。
- 0–2 DTE 默认标「噪声」。
- 只列 5–9 档：现价、主战场、Call墙、Put墙、Max Pain，再加 1–2 个有成交的上下档。
- 不确定就不写那一行，不猜。

## 什么时候才多写
只有用户明确说「能不能买」「交易策略」「给 bot」「详细报告」时，才在价格尺后面加计划。否则一律只出尺。

## 数据
- 先联网拉真实链：Yahoo / thetaOwl / Option Chain Live / UOA。
- 标清截止日和来源。盘前标盘前。
- 不装整条链读到 2027。

## 读链要点
- Vol/OI >2–3 且权利金大 → 像新开仓。
- 打 Ask = 主动买；打 Bid = 主动卖；Mid = 疑价差。
- 看权利金，不看张数。
- Call 和 Put 同时放量 = 对赌。
- 第二天 OI 上升才确认开仓。
- 0–2 DTE 当噪声。

## 不要做
- 不因 Call 放量就说能买。
- 不推荐裸卖。
- 不把 0–2 DTE 天量当短线信号。
- 不编造行权价。
