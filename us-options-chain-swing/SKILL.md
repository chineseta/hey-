# us-options-chain-swing

## 用途
读美股个股期权链，找 1–10 天短线方向信号。只读链，不给买卖建议，除非用户明确问「能不能买」。

## 触发
期权链、异常活动、Vol/OI、Call/Put 墙、IV rank、skew、expected move、近月开仓、读链。

## 数据范围（必须写进报告）
- 数据截止日：默认 9/14 收盘后公开 UOA；盘前会变，需标注。
- 读到的到期日：只列实际出现的，例如 9/16、9/18、9/25、10/16。
- 不假装读完整条链到 2027。更远只在 flow 列表扫到才提。

## 默认输出框架（v1.2，更好懂版）
1. 标题 + 数据截止日 + 读到哪几个到期月
2. 大白话（2–4 句，先说方向，再说别追）
3. 价格尺（ASCII，现价标 ←）
4. 钱往哪边（Call/Put 金额或张数、IV、expected move）
5. 哪些档值得看（只列链上实际有成交的行权价；每档写离现价多少钱、多少%）
6. 一句话

## 价格尺硬规则（本次改动）
- 禁止编造行权价。只列该到期日链上真实存在、且有 Volume 或 OI 的档位。
- 优先选：近月 ATM 上下 2–3 档、Vol/OI 高的档、Call/Put 墙所在档。
- 每个档位必须带来源或「链上有成交」字样；不确定就写「待开盘核对」。
- 若某档是估算，明确标注「估算，非链上真实档」。

## 到期日用法
- 0–2 DTE：噪声，默认忽略或标「到期对打」。
- 7–45 DTE：短线有效区。
- 90 天+：中长线，短线参考弱。

## 读链要点
- Vol/OI >2–3 且权利金大 → 像新开仓。
- 打 Ask = 主动买；打 Bid = 主动卖；Mid = 疑价差，不抄。
- 看权利金金额，不看张数（便宜虚值张数虚高）。
- Call 和 Put 同时放量 = 对赌，不是单边。
- 第二天 OI 上升才确认开仓。

## 结论四选一（仅当用户问能不能买时）
BUY SETUP / WAIT / AVOID / SHORT·HEDGE ONLY

## 不要做
- 不因 Call 放量就说能买。
- 不推荐裸卖做短线方向。
- 不把 0–2 DTE 天量当短线信号。
