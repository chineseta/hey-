# us-options-chain-swing

读美股个股期权链，找 1–10 天短线方向。默认输出：价格尺 + 短线交易策略。

## 触发
期权链、异常活动、Vol/OI、Call/Put 墙、IV rank、skew、expected move、近月开仓、读链、个股 ticker、能不能买、交易策略。

## 默认输出（v1.5）
先出价格尺，紧接出短线策略。不要 JSON，不要长篇原理讲解。

### 1) 价格尺
```
TICKER  YYYY-MM-DD  现价 $XXX  数据截止 收盘/盘中/盘前  到期范围

125  10/16 Call 仓厚 / 上方阻力
115  Call墙
110  Max Pain
100  ★ 主战场（9/18 Call 开仓区）
98   现价
90   Put墙 / 保护
```

硬规则：
- 一行一个真实行权价，禁止编造。
- 从高到低。只列 5–9 档。
- 现价那行只写「现价」。主战场加 ★。
- 注释只用：Call墙 / 上方阻力、主战场（到期+Call/Put+开仓/偏卖）、现价、Put墙 / 保护、Max Pain、噪声、偏保护、偏卖、仓厚。
- 0–2 DTE 标「噪声」。默认读一个月内到期。
- 不确定就不写那一行。

### 2) 短线交易策略（必须跟在尺后面）
用这个骨架，数字必须来自尺上的真实档位：

```
Disclaimer：按期权链结构做的计划，不是投资建议。

状态：WAIT / BUY SETUP / AVOID / SHORT·HEDGE ONLY

开关
- 多头开关：主战场
- 保险丝：Put墙下沿
- 第一目标：Call墙 / Max Pain

主策略表
|项目|计划|
|触发||
|入场||
|止损||
|T1||
|T2||

3. 跌破保险丝

- 0–2 DTE 不当短线方向
- 第二天 OI 上升才把 WAIT 改 SETUP

一句话
```

策略硬规则：
- 现价在主战场下方：默认 WAIT，不追。
- 止损放保险丝下沿，不放随意百分比。
- T1 必须落在尺上有意义的档（Call墙或 Max Pain）。
- 不推荐裸卖。不因 Call 放量就说能买。
- 第一目标 <2R 时写明「偏紧，更干净的是回踩开关档」。

## 数据
先联网拉真实链。标清截止日和来源。默认一个月内到期。不装读到 2027。

## 读链要点
- Vol/OI >2–3 且权利金大 → 像新开仓。
- 打 Ask=主动买；打 Bid=主动卖；Mid=疑价差。
- 看权利金，不看张数。
- Call 和 Put 同时放量=对赌。
- 第二天 OI 上升才确认开仓。
- 0–2 DTE 当噪声。

## 不要做
- 不编造行权价。
- 不把 0–2 DTE 天量当短线信号。
- 不推荐裸卖。
